Model-Based
World Model

Learn the dynamics of a control task from transitions, plan inside the learned model, and watch imagination peel away from reality as the horizon grows.

Deliverable. A working world model: a dynamics model fitted from transitions, rolled forward into the future, with its compounding error measured, its latent state perturbed, and its planning shown to solve a discrete control task in half the real environment steps.

01The environment

The first four panels run the same world: a point mass on a rail, state $s=(x,v)$ and a single force $a\in[-1,1]$. A nonlinear asymmetric spring pulls it toward the origin, and a little drag slows it down:

$$\dot x = v,\qquad \dot v = a - k\,x - c\,v - \gamma\,x^{2} - \beta\,x^{3},\qquad k=1,\ c=0.2,\ \gamma=0.25,\ \beta=0.4$$

The polynomial terms are the whole point. Linear dynamics would be a two-line regression; the $x^{2}$ and $x^{3}$ terms are smooth, deterministic, and just nonlinear enough that capacities one through three separate cleanly. The reward to be maximized regulates the mass to the origin:

$$r(s,a)=-\big(x^{2}+0.1\,v^{2}+0.01\,a^{2}\big)$$

Push the mass off center and watch the true trajectory. This simulation is the ground truth that every model on the page is graded against.

The environment, in Python

The page integrates the dynamics with the same fourth-order Runge–Kutta step the code below uses.

env.pypython
import numpy as np

DT, K, C, GAMMA, BETA, A_MAX = 0.05, 1.0, 0.2, 0.25, 0.4, 1.0

def f(s, a):
    # 1-D point mass on a rail: state s = [x, v]
    x, v = s
    return np.array([v, a * A_MAX - K * x - C * v
                     - GAMMA * x ** 2 - BETA * x ** 3])

def rk4(s, a, dt=DT):
    k1 = f(s, a)
    k2 = f(s + dt / 2 * k1, a)
    k3 = f(s + dt / 2 * k2, a)
    k4 = f(s + dt * k3, a)
    return s + dt / 6 * (k1 + 2 * k2 + 2 * k3 + k4)

step = rk4
reward = lambda s, a: -(s[0] ** 2 + 0.1 * s[1] ** 2 + 0.01 * a ** 2)

02Learning the dynamics model

Collect transitions from the world, then fit a model that predicts the per-step change $\Delta=s'-s$ from the state and action. The model is a polynomial regression $f_\phi(s,a)=s+\Delta_\phi(s,a)$, and capacity is the degree of the polynomial:

$$\Delta_\phi(s,a)=\sum_{i+j+k\le d} \phi_{ijk}\,x^{i}v^{j}a^{k},\qquad \min_\phi\ \mathbb{E}_{(s,a,s')\sim\mathcal{D}}\big\|s'-f_\phi(s,a)\big\|^{2}$$

Degree $d=1$ is a linear model. Degree $2$ adds squares and cross-terms. Degree $3$ adds the cubic terms — including the $x^{2}$ and $x^{3}$ the true dynamics contain. The fit is ridge-regularized least squares on standardized features. More capacity means a smaller one-step error, computed live below on held-out transitions the model never trained on.

Fit the model once and you can roll it forward forever. The function below is exactly what the page does; bootstrap_ensemble trains several models on resampled data so their disagreement can stand in for uncertainty.

world_model.pypython
import numpy as np

class WorldModel:
    """Predicts the per-step change ds = s' - s by ridge regression."""

    def __init__(self, degree=2, ridge=1e-4):
        self.degree, self.ridge = degree, ridge

    def monomials(self):
        d = self.degree
        return [(i, j, k)
                for i in range(d + 1)
                for j in range(d + 1)
                for k in range(d + 1)
                if i + j + k <= d]

    def phi(self, s, a):
        x, v = s
        return np.array([x ** i * v ** j * a ** k for i, j, k in self.expo])

    def fit(self, S, A, S2):
        self.expo = self.monomials()
        P = np.stack([self.phi(s, a) for s, a in zip(S, A)])
        self.mu, self.sigma = P.mean(0), P.std(0) + 1e-8
        X = (P - self.mu) / self.sigma
        y = S2 - S
        n = X.shape[1]
        self.w = np.linalg.solve(X.T @ X + self.ridge * np.eye(n), X.T @ y)

    def step(self, s, a):
        return s + ((self.phi(s, a) - self.mu) / self.sigma) @ self.w

    def rollout(self, s0, actions):
        s, traj = s0, [s0]
        for a in actions:
            s = self.step(s, a)
            traj.append(s)
        return np.array(traj)
ensemble.pypython
def bootstrap_ensemble(data, size=8, degree=2, seed=0):
    """Fit several models to resampled data; their spread is the uncertainty."""
    rng = np.random.default_rng(seed)
    n = len(data)
    models = []
    for _ in range(size):
        idx = rng.integers(0, n, n)
        m = WorldModel(degree)
        m.fit(data.s[idx], data.a[idx], data.s2[idx])
        models.append(m)
    return models

def imagine(models, s0, actions):
    """Roll every member forward; return the mean path and the disagreement."""
    paths = np.stack([m.rollout(s0, actions) for m in models])
    return paths.mean(0), paths.std(0)

03Imagined rollouts and compounding error

Roll the model forward and it talks only to itself: each predicted state becomes the next input. One-step error is tiny; the rollout starts from beyond the training range, so the model extrapolates and the error compounds.

Both trajectories below start at the same off-distribution state. The black path is the true world; the blue path is the model's imagination, drawn to the horizon $H$ you choose. The indigo band is the ensemble's spread.

The measured error is not a coincidence. If the one-step dynamics error is $\epsilon$ and the model is $L$-Lipschitz in its state, the error after $k$ imagined steps is bounded by a geometric sum:

$$\big\|\hat s_k-s_k\big\|\;\le\;\epsilon\sum_{i=0}^{k-1}L^{i}\;=\;\epsilon\,\frac{L^{k}-1}{L-1}$$
A model is supervised learning with adversarial test data. The planner asks about states its own plan creates — exactly the states the training set never covered. Raise capacity and the one-step error falls; raise the horizon and the blue curve bends away regardless.

04Perturbing the latent state

A world model plans in a latent code $z$, not in the raw observation. For this task the latent is two-dimensional — $(z_1,z_2)$ — and a plan is a rollout $\hat s_{k+1}=f_\phi(\hat s_k,a_k)$ started from a perturbed code $\tilde z=z+\delta$. For a task this low-dimensional the code coincides with the physical state, so the perturbation is applied directly to $(x,v)$.

Drag the handle anywhere in the latent plane. Where the grey cloud is dense, the model interpolates among data it has seen and the imagination tracks the world. Drag it into empty space and the model extrapolates — the blue path leaves the black one almost immediately.

05Planning pays for itself

A model is only worth the data if it converts one real step into many imagined ones. Dyna does exactly that: after each real transition, sample a pair $(s,a)$ already seen, roll it through the learned model, and apply the same Q-learning backup to the fabricated transition.

$$Q(s,a)\leftarrow Q(s,a)+\alpha\big[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\big]$$

The point mass has a continuous state space, and tabular Q-learning needs a finite one. So this last experiment runs on a small discrete maze: the same "steer to a target" control task, with the position reduced to cells. The model-free learner (grey) updates only from real experience. The model-based learner (black) also plans: each real step is followed by $n_{\text{plan}}$ backups on transitions its own tabular model produced. Both see the same episodes; the only difference is how far each one stretches them.

The plan step is the whole trick, and it is three lines of code. The only thing it uses that Q-learning does not is the learned model.

dyna.pypython
import numpy as np

def dyna_q(env, episodes=120, n_plan=8,
           alpha=0.2, gamma=0.9, eps=0.2):
    """Tabular Dyna-Q: one real step, then n_plan imagined updates."""
    Q, model, seen = {}, {}, []
    for _ in range(episodes):
        s = env.reset()                              # discrete cell id
        while True:
            if np.random.rand() < eps:
                a = np.random.randint(env.n_actions)
            else:
                a = int(np.argmax([Q.get((s, k), 0.0)
                                   for k in range(env.n_actions)]))
            s2, r, done = env.step(s, a)
            td = r + gamma * max(Q.get((s2, k), 0.0)
                                 for k in range(env.n_actions)) - Q.get((s, a), 0.0)
            Q[(s, a)] = Q.get((s, a), 0.0) + alpha * td
            if (s, a) not in model:                 # learn the model
                model[(s, a)] = (s2, r)
                seen.append((s, a))
            for _ in range(n_plan):                  # plan with the model
                sp, ap = seen[np.random.randint(len(seen))]
                ns, rp = model[(sp, ap)]
                td = rp + gamma * max(Q.get((ns, k), 0.0)
                                      for k in range(env.n_actions)) - Q.get((sp, ap), 0.0)
                Q[(sp, ap)] = Q.get((sp, ap), 0.0) + alpha * td
            s = s2
            if done:
                break
    return Q

With a continuous action space you would replace the tabular backup with model-predictive control — sample action sequences, roll them through the model, execute only the first action of the best one, then replan.

plan.pypython
import numpy as np

def random_shooting(model, s0, horizon, n_candidate, rng, gamma=0.99):
    """Model-predictive control: sample action sequences, keep the best."""
    best_u, best_ret = None, -np.inf
    for _ in range(n_candidate):
        U = rng.uniform(-A_MAX, A_MAX, size=horizon)
        s, ret = s0, 0.0
        for k, a in enumerate(U):
            ret += gamma ** k * reward(s, a)
            s = model.step(s, a)
        if ret > best_ret:
            best_ret, best_u = ret, U
    return best_u[0], best_ret

06Build it, then measure it

The page above is a lab, not a finished project. Rebuild it, then answer the questions it raises.

Lab · implementation plan
  1. Simulate the world. Integrate the point mass with a fourth-order Runge–Kutta step and log transitions $(s,a,s')$. Everything downstream is graded against this.
  2. Fit the dynamics model. Standardize polynomial features of $(x,v,a)$, add a ridge term, and solve the normal equations once per capacity — linear, quadratic, cubic.
  3. Roll it out. Feed each prediction back as the next input and measure $\|\hat s_k-s_k\|$ against the real trajectory. Sweep the horizon and watch the curve bend.
  4. Build an ensemble. Refit on resampled data. Report the mean path and the spread; the spread is the model's own estimate of where it is unsure.
  5. Perturb the latent. Move the start code out of the data cloud and confirm the imagination diverges — the operational meaning of "the model is only valid on-distribution".
  6. Close the loop with planning. Add Dyna-Q, sweep $n_{\text{plan}}$, and measure the real environment steps each learner needs to reach a fixed solve threshold.
  7. Compare fairly. Hold the reward, the state space, and the seeds fixed across both learners; report sample efficiency in real steps, not wall-clock.

Measure three numbers: real steps to a fixed solve threshold, one-step dynamics error by capacity, and the horizon at which the imagined trajectory leaves a fixed error budget. Reaching the same threshold in fewer real steps is the case for the model; the horizon at which imagination collapses is the price.

From here the natural next step is to stop writing the model down at all and let a neural network learn the latent dynamics end-to-end — the Dreamer and MuZero line of Chapter 13, where the model is trained for the plans it will be asked to produce rather than for accuracy on the data it was given.
