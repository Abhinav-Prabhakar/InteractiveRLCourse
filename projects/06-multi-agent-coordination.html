Multi-Agent Coordination

Two agents, two landmarks, one shared reward. Train independent learners, a shared-critic MAPPO team and a monotone QMIX team in the same world, then take a partner away and watch what the coordination was worth.

01The cooperative benchmark

Cooperative multi-agent RL replaces one policy with a joint policy $\pi(\mathbf{a}\mid s)=\prod_i \pi_i(a_i\mid o_i)$. Every agent receives the same team reward, so the objective is a single number that no agent can improve alone:

$$J(\pi)=\mathbb{E}_{\pi}\!\Big[\textstyle\sum_{t\ge 0}\gamma^{t}R_{t+1}\Big],\qquad \mathbf{a}_t\sim\pi(\cdot\mid s_t),\quad a_{i,t}\sim\pi_i(\cdot\mid o_{i,t})$$

The benchmark is a 5×5 grid with two agents and two landmarks. An agent sees its own cell and its partner's cell — nothing else. Each step, the team earns a dense distance term and a bonus for every landmark inside a king-move of an agent, plus a completion bonus when both landmarks are covered. Colliding costs the team.

$$r_{t+1}=-\sum_{k=1}^{2}0.04\,d_k\;+\;0.3\sum_{k=1}^{2}\mathbf{1}[d_k\le 1]\;+\;0.8\,\mathbf{1}[\text{both covered}]\;-\;0.2\,\mathbf{1}[\text{same cell}]$$

This is the smallest task that still separates the three learning architectures. A lone agent can touch both landmarks if it runs; two agents only win the completion bonus every step if they split the work and stay split. That division of labour is the coordination the project is about.

Deliverable. A joint-policy visualiser, three live learning curves, and a measured table of return lost when an agent is disabled — the CTDE team versus the independent baseline.

The environment, reward and joint state fit in forty lines. The file below is the exact transition used by the page.

coverage_env.pypython
import numpy as np

GRID = 5
LANDMARKS = [(0, 0), (4, 4)]
N_AGENTS, N_ACTIONS, T_MAX = 2, 5, 20
GAMMA = 0.95

def manhattan(a, b):
    return abs(a // GRID - b // GRID) + abs(a % GRID - b % GRID)

def chebyshev(a, b):
    return max(abs(a // GRID - b // GRID), abs(a % GRID - b % GRID))

def reset(rng):
    cells = rng.choice(GRID * GRID, size=N_AGENTS, replace=False)
    return [int(c) for c in cells]

def local_obs(cells, i):
    # decentralized: own cell and the partner's cell
    return cells[i] * (GRID * GRID) + cells[1 - i]

def move(cell, a):
    r, c = divmod(cell, GRID)
    r += (a == 0) - (a == 2)          # up / down
    c += (a == 1) - (a == 3)          # right / left
    r, c = min(max(r, 0), GRID - 1), min(max(c, 0), GRID - 1)
    return r * GRID + c

def step(cells, actions):
    nxt = [move(c, a) for c, a in zip(cells, actions)]
    reward, covered = 0.0, 0
    for lm in LANDMARKS:
        near = [chebyshev(c, lm) <= 1 for c in nxt]
        reward -= 0.04 * min(manhattan(c, lm) for c in nxt)
        if any(near):
            reward += 0.3
            covered += 1
    if covered == 2:
        reward += 0.8
    if nxt[0] == nxt[1]:
        reward -= 0.2
    return nxt, reward, covered

The joint state for the critic is the pair of cells; the joint action is the pair of moves. Execution is decentralized: each actor conditions on $o_i$ alone.

02Centralized training, decentralized execution

CTDE splits what an agent knows at training time from what it needs at execution time. Training may use the joint state $s$ and every agent's action; execution uses only $o_i$. The shared critic turns a single team scalar into per-agent advantages:

$$A_i(s,\mathbf{a})=Q^{\pi}(s,\mathbf{a})-V^{\pi}(s),\qquad V^{\pi}(s)=\mathbb{E}_{\pi}\!\Big[\textstyle\sum_{t\ge0}\gamma^t R_{t+1}\mid s_0=s\Big]$$

MAPPO learns a decentralized actor $\pi_i(a_i\mid o_i)$ and a centralized critic $V(s)$; the actor update is a clipped policy gradient weighted by the shared-critic advantage. QMIX instead learns per-agent $Q_i(o_i,a_i)$ and combines them with a monotone mixing network:

$$Q_{\text{tot}}(s,\mathbf{a})=f\big(Q_1(o_1,a_1),\dots,Q_N(o_N,a_N);s\big),\qquad \frac{\partial Q_{\text{tot}}}{\partial Q_i}\ge 0$$

That derivative constraint is the whole trick. If every partial derivative is non-negative, the joint greedy action factorises into per-agent greedy actions — so execution never needs the joint state or a central mixer.

Implementation plan

  1. Build the world. Grid transitions, the shared reward above, and a joint-state index $s=c_A N+c_B$ for the critic.
  2. Roll out with exploration. ε-greedy for the Q learners; a softmax policy for MAPPO. Every learner sees the same spawns and the same number of episodes.
  3. Update three ways. Independent TD targets; GAE plus a clipped actor loss with a centralized value; monotone mixing with a team TD target.
  4. Measure coordination. Coverage is the fraction of landmark-steps covered; specialisation counts steps where the two agents cover different landmarks.
  5. Break it. Freeze one agent at test time, replay the same starts, and record the return lost.
The baseline is not a straw man. Independent Q-learning is what you get if every agent treats the rest of the team as part of the environment. It is cheap, decentralized, and quietly wrong when the environment is other agents who are also learning.

The shared-critic advantage

Generalized advantage estimation needs one value per joint state. Map it back through the trajectory, normalise, then push each actor along the clipped gradient. The critic is thrown away after training; the actors never see it.

mappo_update.pypython
import numpy as np

def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

def gae(rewards, values, next_values, gamma=0.95, lam=0.95):
    adv, acc = np.zeros_like(rewards), 0.0
    for t in reversed(range(len(rewards))):
        delta = rewards[t] + gamma * next_values[t] - values[t]
        acc = delta + gamma * lam * acc
        adv[t] = acc
    return (adv - adv.mean()) / (adv.std() + 1e-8)

def update(actor, critic, batch):
    # one shared critic sees the joint state; each actor sees only its own obs
    adv = gae(batch.rewards, batch.values, batch.next_values)
    for i in range(N_AGENTS):
        for t in range(len(batch.rewards)):
            o, a, old = batch.obs[t][i], batch.acts[t][i], batch.logp[t][i]
            p = softmax(actor[o])
            ratio = p[a] / old
            surr1 = ratio * adv[t]
            surr2 = np.clip(ratio, 0.8, 1.2) * adv[t]
            coef = adv[t] if surr1 < surr2 else (adv[t] if 0.8 <= ratio <= 1.2 else 0.0)
            actor[o] += LR * coef * ratio * (np.eye(N_ACTIONS)[a] - p)
    critic[batch.joint] += LR_V * adv

The alternative is to keep independent $Q_i$ and let a small hypernetwork turn the global state into non-negative mixing weights. Softplus makes the constraint structural rather than a penalty.

qmix_mixing.pypython
import numpy as np

def softplus(z):
    return np.log1p(np.exp(-np.abs(z))) + np.maximum(z, 0.0)

def mix(qs, g, u, b):
    # w_i = softplus(u_i . g) > 0  -- the monotonicity constraint
    w = [softplus(u[i] @ g) for i in range(N_AGENTS)]
    return sum(wi * qi for wi, qi in zip(w, qs)) + b @ g

def qmix_update(Q, batch, u, b, gamma=0.95):
    qs = np.array([Q[i][batch.obs[i], batch.act[i]] for i in range(N_AGENTS)])
    q_tot = mix(qs, batch.g, u, b)
    q_next = [Q[i][batch.next_obs[i]].max() for i in range(N_AGENTS)]
    y = batch.r + gamma * mix(q_next, batch.next_g, u, b)  # semi-gradient target
    loss = (q_tot - y) ** 2
    # dL/dQ_i = 2 (q_tot - y) w_i, and w_i >= 0 preserves the ordering
    return loss

The third learner is deliberately the simplest: two tables, two TD targets, no sharing.

def independent_update(Q, batch, alpha=0.1, gamma=0.95):
    for i in range(N_AGENTS):
        for o, a, r, no in zip(batch.obs[i], batch.acts[i],
                               batch.rewards, batch.next_obs[i]):
            target = r + gamma * Q[i][no].max()
            Q[i][o, a] += alpha * (target - Q[i][o, a])

05Robustness to agent dropout

Coordination is a dependency. A policy trained with a partner may rely on that partner being there; disabling one at test time is a direct measure of how much of the team return was joint work. Both conditions replay the same start states, so the difference is not sampling noise.

Read the drop alongside the return. A learner that never coordinated has little to lose. The interesting number is the fraction of the team's return that disappears when one actor is frozen.

06What to compare

Run the same budget three times and read four things. Sample efficiency: which curve reaches a positive return first. Coordination: coverage and specialisation, not just return. Joint structure: whether the heatmap has a diagonal ridge — different landmarks are worth more than the same one. Dropout: how much return depends on the partner.

The honest result is usually a trade: centralized training buys coordination and pays for it in brittleness when the team changes. That trade is the design space for every cooperative multi-agent system you will build after this one.
