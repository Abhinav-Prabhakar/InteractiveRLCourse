Swing a torque-limited pendulum up and hold it there with DDPG, TD3 and SAC — then ablate the target-policy smoothing, the twin critics and the entropy temperature and watch the learning curves move.

01The task: a torque-limited pendulum

A pendulum hangs from a fixed pivot. The angle $\theta$ is measured from the upward vertical, so $\theta=0$ is the unstable upright and $\theta=\pm\pi$ is the bottom. The agent applies a torque $u\in[-1,1]$ and pays for being away from upright, for spinning, and for using torque:

$$\ddot\theta \;=\; G\sin\theta \;-\; D\,\dot\theta \;+\; T\,u, \qquad r \;=\; \cos\theta \;-\; 0.05\,\dot\theta^{2} \;-\; 0.002\,u^{2}.$$

The state is $s=(\theta,\dot\theta)$; the action is the scalar torque. Swing-up is the interesting case: gravity pulls the rod down, the correct move near the bottom is to pump energy by pushing with the motion, and near the top it flips to a stabilising law. A policy must do both without a mode switch.

Deliverable. A reproducible comparison of DDPG, TD3 and SAC on one continuous task — learning curves, a video-like rollout of the learned policy, and a report isolating the effect of target-policy smoothing, twin critics and the entropy temperature.

The in-page learners are honest but small: a fixed nonlinear feature map feeds a linear (affine-in-action) critic instead of an MLP. Every number you see is computed here; the algorithm is exactly the algorithm.

Build plan

  1. Write the environment. A semi-implicit Euler integrator with sub-stepping, a bounded torque, and the reward above. Fixed horizon per episode.
  2. Write the critic. Features $\phi(s)$ and an augmented input $z=[\phi,\,a,\,a\phi]$ so $Q$ is nonlinear in the action and $\partial Q/\partial a$ is a feature-weighted scalar.
  3. Write the actor. DDPG/TD3 output $\mu_\theta(s)=\tanh(w^\top\phi(s))$; SAC outputs $a=\tanh(\mu_\theta(s)+\sigma\varepsilon)$ with a learned $\sigma$.
  4. Add the machinery. Replay buffer, target networks with Polyak averaging, exploration noise; then TD3's twin critics and target smoothing, then SAC's entropy term and temperature.
  5. Train, then ablate. Hold everything fixed and flip one switch at a time; the only thing that may change is the curve.
pendulum_mdp.pypython
import numpy as np

G, DAMP, TORQUE = 9.0, 0.7, 11.0        # gravity, joint damping, max torque
DT, SUB, H = 0.05, 4, 120               # control dt, integrator substeps, horizon

def step(theta, omega, u):
    h = DT / SUB
    for _ in range(SUB):                # semi-implicit Euler, stable at this dt
        acc = G * np.sin(theta) - DAMP * omega + TORQUE * u
        omega = np.clip(omega + acc * h, -18.0, 18.0)
        theta = theta + omega * h
    reward = np.cos(theta) - 0.05 * omega**2 - 0.002 * u**2
    return theta, omega, reward

def features(theta, omega):
    c, s = np.cos(theta), np.sin(theta)
    return np.array([c, s, omega, omega * c, omega * s, 1.0])

The features are fixed; only the weights move. The term $\omega\cos\theta$ is the energy-pumping direction near the bottom, and $\omega\sin\theta$ covers the sides — enough for a linear actor to swing up.

02Three learners

All three share the same skeleton — replay buffer, target networks, Gaussian exploration — and differ only in what they add. Start with the critic, which every one of them needs.

critic.pypython
import numpy as np

class Critic:
    def __init__(self, dim=13, seed=0):
        rng = np.random.default_rng(seed)
        self.w = 0.01 * rng.standard_normal(dim)
    def z(self, phi, a):
        return np.concatenate([phi, [a], a * phi])      # Q is affine in a, curved in s
    def q(self, phi, a):
        return float(self.w @ self.z(phi, a))
    def dq_da(self, phi, a):
        return self.w[6] + float(self.w[7:] @ phi)      # derivative used by the actor

DDPG — a deterministic actor

Deep Deterministic Policy Gradient learns a deterministic $\mu_\theta(s)$ and pushes it up the critic's action-gradient. No policy distribution, no expectation over actions — just the chain rule through $Q$:

Only the second factor depends on the actor's parameters; the first is read off the critic. Because the gradient flows through $Q$, the actor must be updated on the same states the critic was just trained on — which is why the actor and the critic share each minibatch.

ddpg.pypython
def ddpg_update(agent, tr):
    phi, a, r, phi2 = tr.phi, tr.a, tr.r, tr.phi2
    a2 = np.tanh(agent.actor_target @ phi2)                 # bootstrap action
    y  = r + agent.gamma * agent.critic_target.q(phi2, a2)  # TD target
    err = agent.critic.q(phi, a) - y
    agent.critic.w -= agent.lr_c * 2 * err * agent.critic.z(phi, a)

    a_ = np.tanh(agent.actor @ phi)                         # deterministic policy gradient
    dq = agent.critic.dq_da(phi, a_)
    agent.actor -= agent.lr_a * (-dq * (1 - a_**2)) * phi
    polyak(agent.actor_target, agent.actor, agent.tau)      # slow target networks
    polyak(agent.critic_target, agent.critic, agent.tau)

TD3 — three fixes to DDPG

Twin Delayed DDPG treats DDPG's failure mode — a critic that confidently over-estimates — with three changes. Twin critics train two $Q$'s and take the smaller for the target, so optimism costs. Target-policy smoothing adds clipped noise to the target action, which keeps the critic from sharpening a spike at one action. Delayed updates let the critic catch up before the actor moves.

td3.pypython
def td3_update(agent, tr):
    phi, a, r, phi2 = tr.phi, tr.a, tr.r, tr.phi2
    a2 = np.tanh(agent.actor_target @ phi2)
    eps = np.clip(agent.target_sigma * np.random.randn(),
                  -agent.target_clip, agent.target_clip)
    a2 = np.clip(a2 + eps, -1, 1)                           # target-policy smoothing
    y = r + agent.gamma * min(agent.q1_target.q(phi2, a2),
                              agent.q2_target.q(phi2, a2))  # pessimistic twin min
    for q in (agent.q1, agent.q2):
        err = q.q(phi, a) - y
        q.w -= agent.lr_c * 2 * err * q.z(phi, a)
    if agent.updates % agent.policy_delay == 0:             # delayed actor
        a_ = np.tanh(agent.actor @ phi)
        dq = agent.q1.dq_da(phi, a_)
        agent.actor -= agent.lr_a * (-dq * (1 - a_**2)) * phi
        polyak(agent.actor_target, agent.actor, agent.tau)
        polyak(agent.q1_target, agent.q1, agent.tau)
        polyak(agent.q2_target, agent.q2, agent.tau)

SAC — maximum entropy

Soft Actor-Critic stops optimising return alone. It optimises return plus the entropy of its own policy, so it stays stochastic until the data says otherwise — an exploration bonus that fades exactly where a deterministic policy would over-commit:

The actor is now a squashed Gaussian, $a=\tanh(\mu_\theta(s)+\sigma\varepsilon)$, and $\sigma$ is learned. In the target, the entropy term appears as $-\alpha\log\pi$ inside the bootstrap, which rewards visiting states whose actions are still uncertain. The temperature $\alpha$ trades reward against entropy; it can be fixed or tuned automatically to a target entropy.

sac.pypython
def sac_update(agent, tr):
    phi, a, r, phi2 = tr.phi, tr.a, tr.r, tr.phi2
    sigma = np.exp(np.clip(agent.log_std, -3, 1))
    eps = np.random.randn()
    mu = agent.mean @ phi
    a_ = np.tanh(mu + sigma * eps)                          # reparameterised sample
    logp = -0.5 * eps**2 - agent.log_std - 0.5 * np.log(2 * np.pi)

    a2 = np.tanh(agent.mean @ phi2 + sigma * np.random.randn())
    q2 = min(agent.q1_target.q(phi2, a2), agent.q2_target.q(phi2, a2))
    y  = r + agent.gamma * (q2 - agent.alpha * logp)        # entropy in the target

    for q in (agent.q1, agent.q2):
        err = q.q(phi, a) - y
        q.w -= agent.lr_c * 2 * err * q.z(phi, a)

    dq = agent.q1.dq_da(phi, a_)
    agent.mean    -= agent.lr_a * (agent.alpha * eps / sigma - dq * (1 - a_**2)) * phi
    agent.log_std -= 0.5 * agent.lr_a * agent.alpha * (eps**2 - 1)
    if agent.auto_alpha:                                    # target entropy = -1
        agent.alpha += agent.lr_alpha * (logp + agent.target_entropy)
        agent.alpha = float(np.clip(agent.alpha, 0.01, 2.0))
    polyak(agent.q1_target, agent.q1, agent.tau)
    polyak(agent.q2_target, agent.q2, agent.tau)
One simplification, stated plainly. The critic is linear in the augmented features, and the SAC entropy is measured on the pre-squash variable — the $\tanh$ log-determinant correction is dropped. These keep the page's arithmetic exact and cheap; they change nothing about which failure mode each algorithm fixes.

04Ablating the three fixes

Change exactly one thing and the curve tells you whether it mattered. The config agent obeys the toggles below; the reference agent is full TD3 — twin critics, target smoothing and delayed updates all on — trained in lockstep on the same seeds. Toggling a fix on should pull the config curve toward the reference.

If the entropy slider is live (SAC), you are moving the temperature $\alpha$: up and the config stays exploratory and slow to sharpen; down and it behaves like a deterministic actor with a vestigial noise term. Auto-α tunes it to a target entropy instead.

The ablation is the report. Hold the seeds, the replay buffer, the feature map and the optimisers fixed; flip only target smoothing, only the twin critics, only the temperature — and let the curves, not the prose, make the case. A fix that does not move the curve on this task is not a fix, it is a habit.

Everything here extends straight to a real MuJoCo or PyBullet benchmark: swap the pendulum for the environment, the feature map for an MLP, and keep every algorithm identical.
