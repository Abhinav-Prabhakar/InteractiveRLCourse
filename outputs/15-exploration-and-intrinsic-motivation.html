Exploration and
Intrinsic Motivation

When the task reward says nothing, the agent has to invent a reason to look around — a bonus for wherever it has not yet been.

01The sparse-reward problem

Every method so far quietly assumed reward arrives often enough to shape a value function. In a sparse-reward task it does not: the agent can act for thousands of steps and observe nothing but zero. A greedy policy on a flat value function has nothing to prefer, and $Q$-learning has no gradient to follow.

The fix is to let the agent manufacture its own reward from experience and add it to the task reward:

$$r_t \;=\; r^{e}_t \;+\; r^{i}_t$$

Here $r^{e}_t$ is the extrinsic reward the environment hands out, and $r^{i}_t$ is an intrinsic reward the agent computes for itself. Every section that follows is a different proposal for $r^{i}_t$.

Why this is not just $\varepsilon$-greedy. Random exploration is memoryless and diffusive: it forgets where it has been, so it re-covers the same handful of states forever. An intrinsic reward is a memory of where you have been — and a memory can be valued, planned over, and annealed away.

02Count-based exploration and pseudo-counts

The oldest intrinsic reward is also the most direct: pay the agent for visiting states it has rarely seen. Let $N(s)$ be the number of times $s$ has been visited, and set

$$r^{i}(s) \;=\; \frac{\beta}{\sqrt{N(s)}},\qquad \beta>0 .$$

A state seen $N$ times is worth $\beta/\sqrt{N}$: the bonus decays as familiarity grows, but slowly enough that a well-trodden corridor is never fully abandoned.

Read that back: the bonus is a decreasing function of familiarity, so each visit buys the next one a strictly smaller reward — exploration is a diminishing return on repeat.

Counting is only possible in the tabula rasa world. For a tabular MDP $N(s)$ is just a counter. When states are raw observations — pixels, robot poses — no two states are ever exactly equal, so the counter is always one. The way out is to estimate the count from a density model.

Learn a density model $\rho_n(s)$ over states and write $\rho'_n(s)$ for the same model after one imagined extra observation of $s$. The pseudo-count recovers how many times $s$ would have been seen:

$$\hat N_n(s) \;=\; \frac{\rho_n(s)\big(1-\rho'_n(s)\big)}{\rho'_n(s)-\rho_n(s)},\qquad r^{i}(s)=\frac{\beta}{\sqrt{\hat N_n(s)}} .$$

The denominator is the surprise of one more observation: a state the model already predicts confidently yields a tiny ratio and thus a tiny bonus. This turns any density model — even a neural one — into a novelty signal.

03The Intrinsic Curiosity Module

Counts break down the moment states stop repeating. The Intrinsic Curiosity Module (ICM) replaces the counter with a prediction error: reward the agent for states whose consequences it cannot yet predict. Rather than predicting raw observations, ICM first learns a feature map $\phi$ and builds two small networks on top of it:

$$\hat a_t \;=\; g\big(\phi(s_t),\,\phi(s_{t+1})\big),\qquad \hat\phi(s_{t+1}) \;=\; f\big(\phi(s_t),\,a_t\big)$$

The inverse model $g$ predicts the action that produced the transition; the forward model $f$ predicts the next state's features. They train together on:

$$L_I \;=\; -\log g\big(a_t \mid \phi(s_t),\phi(s_{t+1})\big),\qquad L_F \;=\; \tfrac{1}{2}\big\|\,f(\phi(s_t),a_t)-\phi(s_{t+1})\,\big\|_2^2 .$$

The forward error is the curiosity — scaled into a reward:

$$r^{i}_t \;=\; \frac{\eta}{2}\big\|\,f(\phi(s_t),a_t)-\phi(s_{t+1})\,\big\|_2^2 \;=\; \eta\,L_F^{(t)} ,\qquad \min_{\phi,f,g}\;(1-\beta)\,L_I+\beta\,L_F .$$

The inverse loss is weighted more heavily ($\beta<1$), so the feature map is shaped mostly by what predicts actions. That detail is not cosmetic; it is the entire reason the module survives a stochastic world.

Why a forward model alone gets gamed by randomness. Put the agent in a reward-free room with a television showing random static. No forward model can predict the next frame, so its error stays maximal forever, and the agent parks in front of the TV forever. The encoder is the load-bearing piece: $\phi$ must be useful for predicting which action caused a transition, and static is independent of the action, so no gradient flows into those coordinates. The inverse model throws away what is uncontrollable, and only genuine, learnable surprise is left.

Read the inverse loss back: it forces $\phi$ to keep exactly the features that make the action predictable — and the forward model is then paid only for the surprise that remains.

04Random Network Distillation

ICM pays for surprise about dynamics. Random Network Distillation (RND) pays for surprise about the state itself, and never learns a dynamics model at all. Fix a random network $f_\theta$ and freeze it. Train a second network $g_{\bar\theta}$ to imitate it — but only on the states the agent actually visits:

$$r^{i}_t \;=\; \big\|\,f_\theta(s_{t+1})-g_{\bar\theta}(s_{t+1})\,\big\|_2^2,\qquad L_{\text{RND}} \;=\; \tfrac{1}{2}\big\|\,f_\theta(s)-g_{\bar\theta}(s)\,\big\|_2^2 .$$

On a familiar state the student has caught up and the gap is small; on a novel state the frozen random target is still a surprise. Novelty is the distillation gap between a fixed random function and its pupil — one network, one regression, and no notion of action required.

Normalise before you trust the gap. The reward scale drifts as the student improves, so RND standardises the intrinsic return with a running estimate of its standard deviation, and sums rewards over a non-episodic stream so that novelty persists across episode boundaries. Without this, a task change silently rescales the exploration bonus.

05Curiosity Explorer

Here is the whole idea on a hard-exploration maze. The reward sits at the far end of a perfect maze; a random walk stumbles onto it almost never. The agent plans with value iteration on the current novelty field $\beta/\sqrt{N(s)}$, so its value function is shape — highest exactly where it has not been.

Run it with the bonus on, then turn it off. With the bonus the value function sweeps the maze room by room; without it the field is flat, every action ties, and the agent devolves into a random walk.

06Episodic novelty and Never Give Up

Every bonus so far is lifelong: once a state is familiar, it stays familiar forever. That is exactly wrong when the task requires redoing something you have already done — the agent remembers the room as explored, has no reason to return, and gives up on the episode.

Episodic novelty fixes this by resetting the counter at the start of every episode. Combine it with a lifelong signal and you get the reward used by Never Give Up (NGU):

$$r^{i}_t \;=\; \alpha_t\,\frac{1}{\sqrt{N_e(s_t)}} \;+\; \beta\, r^{\text{life}}_t ,$$

where $N_e(s_t)$ counts visits within the current episode, $r^{\text{life}}_t$ is a lifelong signal such as RND's distillation gap, and $\alpha_t$ decays over training so that episodic novelty matters most early and fades as competence grows.

Never Give Up is the property this buys. Because the episodic bonus returns at every episode boundary, the agent keeps pushing into a room it has already emptied of extrinsic reward instead of retiring there. The lifelong term prevents cross-episode revisiting; the episodic term prevents intra-episode surrender. You need both.

07Summary

Two ways to price surprise. One learns to predict the consequences of your actions; the other never learns, and just measures how far you have drifted from a random fixed function.

Cheat sheet

$$\begin{aligned} r_t &= r^{e}_t + r^{i}_t\\[2pt] r^{i}_{\text{count}}(s) &= \frac{\beta}{\sqrt{N(s)}}\\[2pt] r^{i}_{\text{ICM}}(t) &= \frac{\eta}{2}\big\|\,f(\phi(s_t),a_t)-\phi(s_{t+1})\,\big\|_2^2\\[2pt] r^{i}_{\text{RND}}(t) &= \big\|\,f_\theta(s_{t+1})-g_{\bar\theta}(s_{t+1})\,\big\|_2^2\\[2pt] r^{i}_{\text{NGU}}(t) &= \alpha_t\,\frac{1}{\sqrt{N_e(s_t)}} + \beta\,r^{\text{life}}_t \end{aligned}$$

Everything downstream — hierarchical option discovery, goal-conditioned policies, and the meta-RL of the chapters that follow — is a way of turning this one novelty signal into a curriculum: exploring not just where to go next, but what to try next.
