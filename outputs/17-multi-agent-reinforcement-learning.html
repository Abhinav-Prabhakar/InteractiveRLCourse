Reinforcement Learning

One agent is a decision problem. Several agents learning at once is a moving target — every policy is part of everybody else's environment.

01Markov games

Every chapter so far assumed the world does not care what you learn. Put other learners inside it and that assumption is exactly what fails: the next state now depends on everyone's actions, and everyone keeps changing. A Markov game (or stochastic game) is the object that keeps the Markov property honest under that pressure.

$$\mathcal{M}=\big\langle \mathcal{S},\ \{\mathcal{A}_i\}_{i=1}^{n},\ P,\ \{R_i\}_{i=1}^{n},\ \gamma\big\rangle, \qquad P(s'\mid s,\mathbf{a}),\quad R_i(s,\mathbf{a})=\mathbb{E}\!\left[r_{i,t+1}\mid S_t=s,\ \mathbf{A}_t=\mathbf{a}\right]$$

Here $\mathbf{a}=(a_1,\dots,a_n)$ is the joint action. Each agent maximizes its own return $G_i=\sum_{k=0}^{\infty}\gamma^{k}r_{i,t+k+1}$, and a policy is still local, $a_i\sim\pi_i(\cdot\mid s)$ — the coupling is entirely in the transitions and rewards. Cooperative, competitive, and mixed settings are the same tuple with different reward structure: one shared $R$, $R_1=-R_2$, or anything in between.

Where a single agent asks "which action is best," a game asks "which action is best given what everyone else does." A best response is

$$\pi_i^{\star}\in\arg\max_{\pi_i}\ \mathbb{E}_{\pi_i,\pi_{-i}}\!\big[G_i\big] .$$

A profile $(\pi_1^\star,\dots,\pi_n^\star)$ is a Nash equilibrium when no agent gains by deviating alone:

$$\mathbb{E}_{\pi_i^{\star},\pi_{-i}^{\star}}\!\big[G_i\big]\ \ge\ \mathbb{E}_{\pi_i,\pi_{-i}^{\star}}\!\big[G_i\big] \qquad \forall\,\pi_i,\ \forall\,i .$$
The single-agent $\max$ is gone. A finite game always has at least one Nash equilibrium, but it need not be unique or good, and independent learning need not reach it. Every chapter before this one quietly assumed the argmax was well defined; here it becomes part of the problem.

02Centralized training, decentralized execution

The defining constraint of the field is that at execution each agent must act alone — it cannot read the others' actions, and often cannot see the whole state. A decentralized policy is therefore a function of a local observation only:

$$a_i\sim\pi_i(\cdot\mid o_i),\qquad o_i=\mathcal{O}_i(s).$$

Centralized training, decentralized execution (CTDE) is the observation that this need not constrain training. We can learn each policy with a critic that sees privileged information — the global state $s$ and the full joint action $\mathbf{a}$ — and throw that critic away at the end. Only the actor survives deployment.

$$\underbrace{Q_{\text{tot}}(s,\mathbf{a})}_{\text{centralized critic}}\ \longrightarrow\ \underbrace{\pi_i(a_i\mid o_i)}_{\text{decentralized actor}} .$$

Parameter sharing tightens the loop: when agents are interchangeable, one network $\pi_\theta$ with the agent id appended to $o_i$ learns from every agent's experience at once. Homogeneity becomes sample efficiency.

Why it is not cheating. Nothing at execution reads the central state or the joint action: the experimenter's information is used only to shape the gradient, and $s,\mathbf{a}$ survive only inside the loss, never inside the deployed policy.

03MADDPG: a critic that sees everything

MADDPG is the most direct way to spend centralized training. Give each agent a deterministic actor $\mu_i(o_i;\theta_i)$ and a critic $Q_i^{\mu}(s,a_1,\dots,a_n)$ that is conditioned on every agent's action. The critic's regression target is then an ordinary Bellman target:

$$y_i=r_i+\gamma\,Q_i^{\mu'}\!\big(s',a_1',\dots,a_n'\big)\Big|_{a_j'=\mu_j'(o_j')} .$$

Because the target is conditioned on the other policies, it stays stationary even while those policies improve: from each critic's point of view the environment no longer moves. Each actor then ascends the deterministic policy gradient through its own critic, treating the other agents' actions as fixed inputs:

$$\nabla_{\theta_i}J(\theta_i)=\mathbb{E}\Big[\nabla_{\theta_i}\mu_i(o_i)\;\nabla_{a_i}Q_i^{\mu}(s,a_1,\dots,a_n)\big|_{a_i=\mu_i(o_i)}\Big] .$$

The critic is fit by the usual squared TD error over a replay buffer, using slowly-updated target networks $\mu'$, $Q'$ exactly as in single-agent DDPG. Drop the assumption that every agent sees $s$, and $s\to(o_1,\dots,o_n)$ is the standard partial-observability patch.

Each critic is stationary even though the world is not. That single conditioning choice — feeding the others' actions into the critic — is where CTDE pays for itself. The price is a critic whose input grows with the number of agents, one per agent.

04QMIX: factorizing the joint value

MADDPG centralizes the critic but still learns a joint object. QMIX attacks the joint action space itself. Each agent keeps a small utility $Q_i(o_i,a_i)$, and a mixing network combines them into one joint value using weights that depend only on the global state:

$$Q_{\text{tot}}(s,\mathbf{a})=f_{\phi}\big(Q_1(o_1,a_1),\dots,Q_n(o_n,a_n);\,s\big).$$

Left unconstrained this buys nothing. The trick is a single monotonicity constraint: every mixing weight is non-negative, so $Q_{\text{tot}}$ is non-decreasing in each $Q_i$,

$$\frac{\partial Q_{\text{tot}}}{\partial Q_i}\ \ge\ 0\quad\forall i \qquad\Longrightarrow\qquad \begin{aligned} \arg\max_{\mathbf{a}}Q_{\text{tot}}(s,\mathbf{a}) &=\Big(\arg\max_{a_1}Q_1(o_1,a_1),\ \dots,\\ &\qquad\ \arg\max_{a_n}Q_n(o_n,a_n)\Big) \end{aligned}$$

Read that last identity back: the $\max$ over the exponential joint action space collapses to $n$ independent $\max$es, because a non-decreasing function can never trade one agent's utility off against another's. Decentralized greedy selection is therefore exact, not approximate. Training is off-policy TD on $Q_{\text{tot}}$ with targets from a target network:

$$\mathcal{L}(\phi,\theta)=\mathbb{E}_{\mathcal{D}}\Big[\big(r+\gamma\max_{\mathbf{a}'}Q_{\text{tot}}(s',\mathbf{a}';\phi^-)-Q_{\text{tot}}(s,\mathbf{a};\phi)\big)^{2}\Big] .$$
Monotonicity is the whole story. Non-negative weights are the entire bridge between a joint value and decentralized actors. Loosen the sign and the identity collapses — the greedy actions stop agreeing — which is exactly what the mixing weight below lets you break.

05Cooperative navigation

A $5\times5$ grid, two agents, two landmarks. The agents move simultaneously — stay, up, right, down, left — and both reward their own progress. Each step costs $0.1$; each landmark pays $+1$ the first time an agent covers it; the episode ends once both are covered. There is no random transition and no hidden state, only the coupling.

$$r(s,\mathbf{a})=-0.1\ \text{(per step)}+\mathbf{1}\{\text{a new landmark is covered}\},\qquad \text{end when both are covered}.$$

A joint critic solves this exactly by value iteration over the joint state $s=(p_1,p_2,\text{covered})$:

$$V(s)=\max_{\mathbf{a}}\Big[r(s,\mathbf{a})+\gamma\,V\big(s'(s,\mathbf{a})\big)\Big],\qquad \gamma=0.95 .$$

An independent agent instead solves only its own problem, $\max_{a_i}$, with the other agent invisible. Both players find the same near landmark most attractive, so both chase it and one of them is wasted. Switch the toggle and compare.

Coordination is a property of the value function, not a tie-break. Nothing in either agent's local reward says "go elsewhere"; that advice only exists in the joint value, which is why the centralized critic is the thing that has to see both positions at once.

06Non-stationarity and equilibrium selection

Matching pennies has no randomness, two actions per player, and no coordination problem — and it still defeats independent learning. The row player wants to match, the column player wants to mismatch, so the unique Nash equilibrium is the mixed profile $(\tfrac12,\tfrac12)$ and neither player can commit to an action. Write $p=\mathbb{P}(\text{row plays heads})$ and $q=\mathbb{P}(\text{col plays heads})$; the row player's expected payoff is

$$u_1(p,q)=(2p-1)(2q-1),\qquad u_2(p,q)=-u_1(p,q).$$

Simultaneous gradient ascent on each player's own payoff gives, since $\partial u_1/\partial p=2(2q-1)$ and $\partial u_2/\partial q=-2(2p-1)$,

$$\Delta p_t=\eta\,(2q_t-1),\qquad \Delta q_t=-\eta\,(2p_t-1) .$$

This is a rotation, not a contraction: every step turns the pair $(p,q)$ around $(\tfrac12,\tfrac12)$ by roughly $2\eta$ radians. The Nash equilibrium is the centre of an orbit no independent learner settles on. Run it and the strategy pair circles forever.

Non-stationarity is the mathematical content, not a nuisance. Every convergence proof in the earlier chapters assumed a fixed transition kernel $P(s'\mid s,a)$. Here the kernel is the other learner, and it changes with every update — so the target keeps moving under the agent's feet.

In games with several equilibria the update rule does more than converge; it selects. Coordination games reward both payoff dominance and risk dominance, and the equilibrium independent learners drift into depends on initialization, learning rates, and the order of updates — a choice the theory leaves open and practice fixes by accident.

$$\begin{aligned} \mathcal{M} &= \big\langle \mathcal{S},\{\mathcal{A}_i\},P,\{R_i\},\gamma\big\rangle, \qquad P(s'\mid s,\mathbf{a}),\quad R_i(s,\mathbf{a})\\[2pt] \pi_i^{\star} &\in \arg\max_{\pi_i}\mathbb{E}_{\pi_i,\pi_{-i}}[G_i] \quad\text{(Nash when it holds for every } i)\\[2pt] \nabla_{\theta_i}J(\theta_i) &= \mathbb{E}\Big[\nabla_{\theta_i}\mu_i(o_i)\,\nabla_{a_i}Q_i^{\mu}(s,a_1,\dots,a_n)\big|_{a_i=\mu_i(o_i)}\Big]\\[2pt] \frac{\partial Q_{\text{tot}}}{\partial Q_i}\ge 0 &\Longrightarrow \arg\max_{\mathbf{a}}Q_{\text{tot}}=\big(\arg\max_{a_1}Q_1,\dots,\arg\max_{a_n}Q_n\big)\\[2pt] \Delta p_t &= \eta(2q_t-1),\qquad \Delta q_t=-\eta(2p_t-1) \end{aligned}$$

Everything in the next part builds on this: meta-reinforcement learning makes the task another moving target, distributional RL makes the return a distribution, and imitation learning makes the reward come from demonstrations instead of the environment.
