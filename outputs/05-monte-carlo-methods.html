Monte Carlo Methods

Estimate value from the only thing an agent actually has — episodes it has lived through — by averaging the returns it saw.

01Learning from experience

Dynamic programming needs the model: to back up a state it must know every $P(s'\mid s,a)$. Monte Carlo (MC) methods discard the model and learn from sampled episodes — sequences $S_0,A_0,R_1,\dots,S_T$ produced by interacting with the world or a simulator.

$$v_\pi(s)=\mathbb{E}_\pi\!\left[G_t \mid S_t=s\right]\;\approx\;\frac{1}{|T(s)|}\sum_{t\in T(s)}G_t .$$

Here $T(s)$ is the set of times state $s$ was visited and $G_t$ the return that followed. The expectation is simply replaced by a sample average.

Sampling replaces the model. MC is unbiased and needs no $P$, but a single episode's return can be far from its mean — the price is variance, paid back over many episodes.

02Monte Carlo prediction

Run a batch of episodes under a fixed policy $\pi$ and, for every visit to $s$, record the return that followed from that point. Two bookkeeping rules:

$$\text{first-visit: use the first visit to }s\text{ per episode}\qquad\text{every-visit: use all of them.}$$

Both converge to $v_\pi(s)$ as episodes accumulate. First-visit estimates are independent sample means, which makes them the clean case; every-visit reuses correlated returns but is still consistent. Returns are computed backward in one sweep from the terminal, since $G_t=R_{t+1}+\gamma G_{t+1}$.

03The incremental mean

Storing every return is wasteful. An average can be updated as each new sample arrives:

$$V_{n+1}=V_n+\frac{1}{n}\big(G_n-V_n\big).$$

The estimate moves from the old value by the error $G_n-V_n$, scaled by the shrinking step $1/n$. Replacing $1/n$ with a constant $\alpha$ gives the constant-$\alpha$ form that recurs in every later chapter.

$$V_{n+1}=V_n+\alpha\big(G_n-V_n\big).$$

04Monte Carlo control

Control follows generalized policy iteration: evaluate $q_\pi$ by averaging returns, then make $\pi$ greedy with respect to it. Two things break if done naively — a greedy policy stops exploring, and some $(s,a)$ may never be sampled, so their values never improve.

$$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\frac{1}{N(S_t,A_t)}\big(G_t-Q(S_t,A_t)\big).$$

Exploring starts fixes the first problem by beginning every episode from a random $(s,a)$. ε-soft policies fix it more gently, keeping at least $\epsilon/|\mathcal A|$ probability on every action:

$$\pi(a\mid s)\ \ge\ \frac{\epsilon}{|\mathcal A|},\qquad \pi(a\mid s)=1-\epsilon+\frac{\epsilon}{|\mathcal A|}\ \text{ for the greedy }a .$$

Improving to the ε-greedy policy at every step makes GPI converge to the best ε-soft policy.

05Off-policy prediction

Sometimes $v_\pi$ is wanted for a target policy $\pi$ while a different behavior policy $b$ generates the data — to reuse old episodes, or to explore freely while still learning a greedy target. The two policies assign different likelihoods to the actions actually taken, and importance sampling corrects the gap with their ratio.

$$\rho_{t:T-1}=\prod_{k=t}^{T-1}\frac{\pi(A_k\mid S_k)}{b(A_k\mid S_k)} .$$

$\rho_{t:T-1}$ is the relative probability that $\pi$ rather than $b$ would have produced the suffix $A_t,\dots,A_{T-1}$. It requires $b(a\mid s)>0$ wherever $\pi(a\mid s)>0$. Weighting each return by it gives the ordinary estimator, which is unbiased:

$$V(s)=\frac{\sum_{t\in T(s)}\rho_{t:T-1}\,G_t}{|T(s)|}.$$

06Weighted importance sampling

Ordinary IS is unbiased but its variance is often unbounded: one long episode with many factors above $1$ makes a single term $\rho_{t:T-1}G_t$ enormous. Weighted IS divides by the accumulated weights instead of the count:

$$V(s)=\frac{\sum_{t\in T(s)}\rho_{t:T-1}\,G_t}{\sum_{t\in T(s)}\rho_{t:T-1}} .$$

It is biased for finite $n$, but consistent with far lower variance, so it is the estimator used in practice. Incrementally, with cumulative weight $C$, the update is the ordinary running mean with the step $W_n/C_n$:

$$V_{n+1}=V_n+\frac{W_n}{C_n}\big(G_n-V_n\big),\qquad C_{n+1}=C_n+W_n,\qquad W_n=\rho_{t:T-1}.$$

Setting $C_n=n$, i.e. counting instead of accumulating weights, recovers ordinary IS — the two estimators differ in a single line.

Cheat sheet

$$\begin{aligned} v_\pi(s) &\approx \frac{1}{|T(s)|}\sum_{t\in T(s)}G_t\\[2pt] V_{n+1} &= V_n+\frac{1}{n}\big(G_n-V_n\big)\\[2pt] \rho_{t:T-1} &= \prod_{k=t}^{T-1}\frac{\pi(A_k\mid S_k)}{b(A_k\mid S_k)}\\[2pt] V_{n+1} &= V_n+\frac{W_n}{C_n}\big(G_n-V_n\big),\qquad C_{n+1}=C_n+W_n \end{aligned}$$

The estimates here wait for the episode to end before touching a value; the next chapter — temporal-difference learning — makes the same update from a single step, without waiting for the return.
