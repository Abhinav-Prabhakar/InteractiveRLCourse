Function Approximation

When there are more states than you can ever visit, the value function stops being a table and becomes a function — and every guarantee you got for free has to be earned back.

01Why tables fail

Every method so far stored one number per state. Tabular value iteration, Monte Carlo, TD, Q-learning — all of them wrote $V(s)$ into a slot indexed by $s$. That is exact, and it never generalizes.

$$\big|\,\text{table}\,\big| \;=\; |\mathcal{S}|, \qquad V:\mathcal{S}\to\mathbb{R},\qquad \text{one free parameter per state.}$$

A $5\times5$ grid is $25$ numbers. Swap the grid for a raw observation and the count explodes: an $84\times84$ RGB frame has $256^{3\cdot84\cdot84}\approx 10^{16{,}000}$ distinct images. Store a pointer per state and there is not enough matter in the universe.

The deeper problem is not memory. Even given infinite memory you could never visit $10^{16{,}000}$ states enough times to estimate each one. What you need is generalization: a change to one parameter must change the value of many similar states at once.

The table is an assumption, not an algorithm. Tabular TD and Q-learning are just function approximation with one independent parameter per state, and the independence is what made every convergence proof work. Relax it and you are in new territory.

02Parametric value functions

Replace the table with a function of a small parameter vector $\theta\in\mathbb{R}^{d}$ and a fixed feature vector $x(s)$:

$$v_\theta(s)\;\approx\;v_\pi(s), \qquad v_\theta(s)=\theta^\top x(s)=\sum_{i=1}^{d}\theta_i\,x_i(s), \qquad d\ll|\mathcal{S}| .$$

Read that back: a state is no longer a row in an array, it is a point in $\mathbb{R}^d$, and states with similar features are forced to share a value. For control the same move gives $q_\theta(s,a)$.

The target is to minimize the error, weighted by how often each state is visited:

$$\overline{VE}(\theta)\;=\;\sum_{s}\mu(s)\,\big[\,v_\pi(s)-v_\theta(s)\,\big]^2,$$

where $\mu$ is the state distribution under the policy. The awkward part is that $v_\pi(s)$ is unknown — we only ever see samples of it, and the samples themselves depend on $\theta$.

This is supervised learning with a moving target. If someone handed you the true values $v_\pi(s)$ on a stream of states, this would be ordinary regression. Nobody does. The target is assembled from rewards and the current estimate, so learning and the thing being learned move together.

03Semi-gradient TD(0)

Take one transition $(\,S_t,\,R_{t+1},\,S_{t+1}\,)$ and form the bootstrapped target $U_t=R_{t+1}+\gamma v_\theta(S_{t+1})$. Treat it as fixed and take a stochastic-gradient step on the squared error:

$$ \begin{aligned} J_t(\theta) &= \tfrac12\big[\,U_t-v_\theta(S_t)\,\big]^2 \\[2pt] -\nabla_\theta J_t(\theta) &= \big[\,U_t-v_\theta(S_t)\,\big]\,\nabla_\theta v_\theta(S_t) \end{aligned} $$

The catch is that $U_t$ also contains $\theta$. Differentiating through the bootstrap is the *full* gradient; ignoring that term gives the semi-gradient TD(0) update:

$$\boxed{\;\theta_{t+1}=\theta_t+\alpha\big[\,R_{t+1}+\gamma v_\theta(S_{t+1})-v_\theta(S_t)\,\big]\nabla_\theta v_\theta(S_t)\;}$$

For linear features $\nabla_\theta v_\theta(s)=x(s)$, so the update is a scalar times a vector: $\theta_{t+1}=\theta_t+\alpha\,\delta_t\,x(S_t)$, with $\delta_t=R_{t+1}+\gamma\theta^\top x(S_{t+1})-\theta^\top x(S_t)$.

The third factor is exactly where function approximation is spent: $\nabla_\theta v_\theta(S_t)$ says which parameters to nudge, and because parameters are shared, nudging them moves the value of every other state too. One transition updates the whole curve.

The moving target is the whole story. True gradient descent would differentiate through $U_t$ and descend an honest loss. Semi-gradient does not — it chases a target that moves as $\theta$ moves. That shortcut is what keeps the method online and cheap, and it is exactly what forfeits the convergence guarantee.

04The deadly triad

Three ingredients now sit in the same loop. Any two of them are safe. All three together can, and do, blow up:

$$\underbrace{\text{function approximation}}_{\text{shared }\theta} \;+\;\underbrace{\text{bootstrapping}}_{\text{targets use } v_\theta} \;+\;\underbrace{\text{off-policy data}}_{\mu_b\neq\mu_\pi} \;\Longrightarrow\;\text{possible divergence}.$$

Delete a leg and stability returns. A table instead of shared weights: tabular off-policy Q-learning converges. No bootstrapping: Monte Carlo with function approximation is ordinary SGD on real returns. On-policy data: linear semi-gradient TD converges, and we prove it in the next section. Keep all three and the update operator's matrix can lose the property that made every earlier proof a contraction.

Baird's counterexample

The minimal witness has seven states and two actions. Call states $1$–$6$ the upper ring and state $7$ the lower hub. The dashed action jumps uniformly to one of states $1$–$6$; the solid action goes to state $7$. The behavior policy $b$ plays dashed with probability $6/7$, and therefore lands uniformly on all seven states; the target policy $\pi$ always plays solid. Every reward is $0$, so $v_\pi(s)=0$ for all $s$ — the easiest function imaginable, and one the features can represent exactly.

$$\text{state } i\in\{1,\dots,6\}:\; v_\theta(s_i)=2\theta_i+\theta_8, \qquad \text{state } 7:\; v_\theta(s_7)=\theta_7+2\theta_8,$$

with eight weights for seven states — deliberately dependent features. Run off-policy semi-gradient TD(0) with the importance ratio $\rho_t=\pi(A_t\mid S_t)/b(A_t\mid S_t)$ and $\|v_\theta\|_\infty$ does not merely fail to reach zero: it grows without bound.

The mechanism is a feedback loop. The behavior spends almost all its time on states $1$–$6$, whose target is always $\gamma v_\theta(s_7)$; a positive $v_\theta(s_7)$ pushes all six upward, including the shared $\theta_8$. But $\theta_8$ appears in $v_\theta(s_7)$ with coefficient $2$, so the target rises faster than the values chasing it, and the one state that could correct it — state $7$ — is almost never updated.

No step size saves you. Shrinking $\alpha$ only slows the exponential; it never changes its sign. Even the exact expected update — no sampling noise at all — diverges here, because the instability lives in the operator, not the noise.

05Linear function approximation

With linear features the whole analysis collapses to a linear system. Take the expectation of the semi-gradient update under the state distribution $\mu$ and everything becomes affine in $\theta$:

$$\mathbb{E}_\mu[\Delta\theta]=\alpha\,(\mathbf{b}-A\theta),\qquad A=\mathbb{E}_\mu\!\Big[\,x(S_t)\big(x(S_t)-\gamma x(S_{t+1})\big)^\top\Big],\qquad \mathbf{b}=\mathbb{E}_\mu\big[R_{t+1}\,x(S_t)\big].$$

If the iteration settles anywhere it settles at the TD fixed point:

$$A\theta_{\text{TD}}=\mathbf{b}\quad\Longrightarrow\quad \theta_{\text{TD}}=A^{-1}\mathbf{b}.$$

Why on-policy is safe

Under on-policy sampling the states $S_t$ and $S_{t+1}$ share the same marginal $\mu$, so Cauchy–Schwarz gives the key contraction:

$$\theta^\top A\theta=\mathbb{E}\big[v(S_t)^2\big]-\gamma\,\mathbb{E}\big[v(S_t)v(S_{t+1})\big] \;\ge\;(1-\gamma)\,\mathbb{E}\big[v(S_t)^2\big]>0,$$

with $v(s)=\theta^\top x(s)$. Positive definiteness means the iteration is a contraction, $A$ is invertible, and TD converges. This is the load-bearing step: the third line above is exactly where off-policy learning is spent — drop the shared marginal and the Cauchy–Schwarz bound fails.

$$\overline{VE}(\theta_{\text{TD}})\;\le\;\frac{1}{1-\gamma}\;\min_\theta \overline{VE}(\theta).$$

Read it back: TD cannot do better than the best value function in the span of the features, and it pays a factor $1/(1-\gamma)$ for the privilege of bootstrapping. As $\gamma\to1$ that penalty grows without bound — the price of a target that is allowed to move.

Linear TD is the only TD method with this guarantee. Nonlinear approximation gives no such fixed-point theorem. Off-policy linear TD repairs the objective instead: gradient-TD methods (GTD, TDC) minimize a different, well-behaved loss and converge again — at the cost of a second set of parameters and slower updates.

Cheat sheet

$$\begin{aligned} v_\theta(s) &= \theta^\top x(s), \qquad \nabla_\theta v_\theta(s)=x(s)\\[2pt] \delta_t &= R_{t+1}+\gamma\,v_\theta(S_{t+1})-v_\theta(S_t)\\[2pt] \theta_{t+1} &= \theta_t+\alpha\,\delta_t\,\nabla_\theta v_\theta(S_t)\\[2pt] \theta_{\text{TD}} &= A^{-1}\mathbf{b}, \qquad A=\mathbb{E}_\mu\big[x(S_t)(x(S_t)-\gamma x(S_{t+1}))^\top\big]\\[2pt] \overline{VE}(\theta_{\text{TD}}) &\le \tfrac{1}{1-\gamma}\min_\theta \overline{VE}(\theta) \end{aligned}$$

Everything from here on — DQN's replay buffer, PPO's clipped ratio, DPO's implicit reward — is one more answer to the same two questions: which $v_\theta$ do you choose, and how do you keep the deadly triad from biting.
