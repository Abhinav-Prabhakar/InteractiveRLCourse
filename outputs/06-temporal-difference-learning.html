Temporal-Difference
Learning

Learn a value estimate from the very next reward — before the episode is over — then let a single $\max$ decide whether the agent plays it safe or plays it best.

01Learning from a guess

A temporal-difference method learns a guess from another guess. Monte Carlo waits for the episode to end and averages the return $G_t$ it actually saw; dynamic programming needs the full model to back up. TD does neither — it takes the one reward it did observe and replaces the unknown rest with its own running estimate:

$$V(S_t)\;\leftarrow\;V(S_t)+\alpha\big[R_{t+1}+\gamma\,V(S_{t+1})-V(S_t)\big]$$

The bracketed quantity is the TD error $\delta_t$ — the gap between what the estimate predicted and the one-step target it just received:

$$\delta_t \;=\; R_{t+1}+\gamma\,V(S_{t+1})-V(S_t),\qquad V(S_t)\leftarrow V(S_t)+\alpha\,\delta_t .$$

Read the target back: $R_{t+1}+\gamma V(S_{t+1})$ keeps the sampled reward and pins everything after it on $V$'s own opinion. At $\gamma=0$ the target is just $R_{t+1}$; replace $V(S_{t+1})$ by the actual return $G_{t+1}$ and the target becomes $G_t$ — Monte Carlo. $n$-step methods (Chapter 7) fill the interval in between.

The bias–variance trade, in one target. $R_{t+1}+\gamma V(S_{t+1})$ is biased — it trusts $V$, which is wrong early — but its variance is tiny, because only one random reward enters. Monte Carlo's target $G_t$ is unbiased but high-variance. TD usually needs far less experience to reach the same accuracy.

02TD(0) prediction

Prediction is the warm-up: fix the policy, learn its state-value function online. The testbed is the smallest interesting one — a five-state random walk. From the middle the agent steps left or right with equal probability; the left terminal pays $0$, the right terminal pays $+1$.

$$\mathbb{P}(S_{t+1}=s\pm 1\mid S_t=s)=\tfrac12,\qquad R_{t+1}=\mathbf{1}\{S_{t+1}=\text{right terminal}\}$$

Every step applies the rule of Section 01 to the state it just left; a terminal state has value $0$. Run it and the estimates crawl toward the true values $V_\pi$.

03Control: Sarsa and Q-learning

Now let values drive actions. The bootstrapped target splits in two, depending on what the agent backs up from the next state. Both algorithms update

$$Q(S_t,A_t)\;\leftarrow\;Q(S_t,A_t)+\alpha\big[R_{t+1}+\gamma\,\square - Q(S_t,A_t)\big]$$

where the blank is either the value of the action the policy will actually take, or the value of the best action available.

Sarsa — on-policy

Sarsa plugs in the next action $A_{t+1}$ that the behaviour policy — here $\varepsilon$-greedy — really selects. The update consumes the quintuple $(S_t,A_t,R_{t+1},S_{t+1},A_{t+1})$ whose initials give the algorithm its name:

$$Q(S_t,A_t)\;\leftarrow\;Q(S_t,A_t)+\alpha\big[R_{t+1}+\gamma\,Q(S_{t+1},A_{t+1})-Q(S_t,A_t)\big]$$

It evaluates the policy it is running, exploration and all.

Q-learning — off-policy

Q-learning ignores what the behaviour policy does next and plugs in the greedy action instead:

$$Q(S_t,A_t)\;\leftarrow\;Q(S_t,A_t)+\alpha\big[R_{t+1}+\gamma\max_a Q(S_{t+1},a)-Q(S_t,A_t)\big]$$

It evaluates the greedy policy directly, no matter how the data was generated.

Expected Sarsa sits between them: back up the expectation $\sum_a \pi(a\mid S_{t+1})\,Q(S_{t+1},a)$ under the policy instead of one sampled $A_{t+1}$. Same target in expectation as Sarsa, less variance; with $\pi$ greedy it is exactly Q-learning.

The only difference is one symbol: $Q(S_{t+1},A_{t+1})$ versus $\max_a Q(S_{t+1},a)$. Sarsa's target is the value of the policy that is acting, so it prices in the cost of its own $\varepsilon$-exploration. Q-learning's target is the value of the greedy policy, learned from an exploring one. That is exactly what on-policy and off-policy mean.

04Maximization bias and Double Q-learning

The $\max$ in Q-learning is not a neutral operation. Over noisy estimates it is optimistic:

$$\mathbb{E}\Big[\max_a Q(s,a)\Big]\;\ge\;\max_a \mathbb{E}\big[Q(s,a)\big]$$

with strict inequality whenever the noise can change which action looks best. A $\max$ over several errors keeps the most optimistic one, so the bootstrapped target is biased high — and the bias, fed back through the update, can make the agent prefer a genuinely worse action. This is maximization bias.

The canonical trap has two states. From the start $A$ you choose right — the episode ends at once with reward $0$ — or left, which also pays $0$ but moves you to $B$. From $B$ run $k$ actions, every one terminating with a noisy reward $r\sim\mathcal{N}(-0.1,1)$.

$$Q_*(A,\text{right})=0,\qquad Q_*(B,\cdot)=-0.1 \quad\Longrightarrow\quad \text{always take right}$$

Every action from $B$ is negative on average, so $B$ is worth $-0.1$ and right is optimal. But $\max_a Q(B,a)$ is a maximum over $k$ noisy estimates and therefore biased upward — often above $0$ — so Q-learning keeps believing left is worth taking. Double Q-learning

Double Q-learning removes the bias by keeping two independent estimates, $Q_1$ and $Q_2$, and splitting the roles: one chooses the maximizing action, the other scores it. With probability $\tfrac12$,

$$Q_1(S_t,A_t)\;\leftarrow\;Q_1(S_t,A_t)+\alpha\Big[R_{t+1}+\gamma\,Q_2\!\big(S_{t+1},\arg\max_a Q_1(S_{t+1},a)\big)-Q_1(S_t,A_t)\Big]$$

and with probability $\tfrac12$ the same update with $Q_1\leftrightarrow Q_2$; the behaviour policy is $\varepsilon$-greedy on the sum $Q_1+Q_2$. Because the selection is made by one estimate and the value read from the other, a single lucky sample no longer inflates its own target.

Selection and evaluation must be decoupled. This is not a tabular curiosity: the same fix turns DQN into Double DQN, replacing $\max_{a'}Q_{\theta^-}(s',a')$ with $Q_{\theta^-}\!\big(s',\arg\max_{a'}Q_\theta(s',a')\big)$.

05Cliff walking

A $4\times 12$ grid. Start bottom-left, goal bottom-right, and a cliff running along the bottom edge between them. Every step costs $-1$; stepping into the cliff costs $-100$ and teleports the agent back to the start. The task was built to separate on-policy from off-policy learning.

$$r=\begin{cases}-100 & \text{enter cliff (reset to start)}\\ -1 & \text{otherwise}\end{cases}\qquad \varepsilon\text{-greedy},\quad \gamma=1$$

The optimal path hugs the cliff edge: up one row, straight across, down. But that edge is exactly where $\varepsilon$-exploration occasionally shoves the agent into the pit. Drag the sliders and run both learners side by side.

The two learners converge to different answers on purpose. Q-learning learns the optimal path along the cliff edge and, while exploring, keeps falling off it. Sarsa learns a longer path well away from the edge — at the default settings, usually along the top row — because its target prices in the $\varepsilon$-greedy mistakes it will actually make. Sarsa is the better policy to run while learning; Q-learning is the better policy to converge to.
