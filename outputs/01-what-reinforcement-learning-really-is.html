What Reinforcement Learning
Really Is

An agent acts, the world pushes back, and a single scalar is the only teacher — here is the language of that loop, and why the loss functions you already know cannot fill in for it.

01The agent–environment loop

Reinforcement learning is one loop repeated forever. An agent observes a state, takes an action, and the environment answers with a reward and a next state. Nothing else is handed over.

Formally, at each step $t$ the agent receives $S_t\in\mathcal{S}$ and picks $A_t\in\mathcal{A}$ from its policy $\pi(a\mid s)$. The environment then samples the next state and reward from its dynamics:

$$S_{t+1}\sim P(\cdot\mid S_t,A_t),\qquad R_{t+1}=R(S_t,A_t,S_{t+1})$$

Unroll the loop and you get a trajectory — the only data RL ever sees:

$$\tau=(S_0,A_0,R_1,S_1,A_1,R_2,S_2,\dots)$$
The reward is the only teacher. The policy is what the agent controls; the scalar is everything it is told. Change the reward and you have changed the problem — not merely its difficulty.

02The reward, and what it buys you

A reward is a scalar and nothing more — no gradient, no label, no hint about which action was correct. The reward hypothesis says every goal worth pursuing can be written as maximizing expected cumulative reward. That cumulative total is the return:

$$G_t=\sum_{k=0}^{\infty}\gamma^{k}R_{t+k+1},\qquad 0\le\gamma<1$$

The discount $\gamma$ keeps the sum finite and prices how much the agent cares about the future. The job, then, is to pick a policy that makes the return large in expectation:

$$J(\pi)=\mathbb{E}_{\tau\sim\pi}\!\big[G_0\big]=\mathbb{E}\!\Big[\textstyle\sum_{t\ge0}\gamma^{t}R_{t+1}\Big]$$

Read that last line back: $J$ averages over trajectories the policy itself generates — the thing being graded decides which data it gets to see.

Because $G$ is built from $R$, the optimal policy is a function of the reward. Drag one reward and the greedy arrows swing.

03Evaluative vs. instructive feedback

Supervised learning is told the right answer for every input — instructive feedback. RL is told only how good the last action turned out — evaluative feedback. The two objectives look similar on the page and are nothing alike in practice:

$$\text{supervised: }\min_{\theta}\sum_i \ell\!\big(f_\theta(x_i),\,y_i\big) \qquad\text{vs.}\qquad \text{RL: }\max_{\theta}\ \mathbb{E}_{\tau\sim\pi_\theta}\!\big[G_0\big]$$

Three consequences fall out immediately. Credit assignment: which of the last hundred actions earned this reward? Non-stationarity: the policy reshapes the very distribution it trains on. Exploration: a good action must be tried before it can ever be learned.

Instructive — a target for every input

$y_1$· $y_2$· $y_3$· $y_4$

Evaluative — a scalar after every action

$+1$· $0$· $-0.5$· $+0.2$
A label is a teacher; a scalar is a grade. Supervised learning can copy the label directly. RL must first discover which action earned the grade — usually by trying it, and living with the cost of having tried it.

04The exploration–exploitation dilemma

A greedy agent always takes $a^{*}_{t}=\arg\max_a \hat Q_t(a)$, where $\hat Q_t$ is its current estimate. That is myopic: an action that looks mediocre now may be worth taking precisely to find out what lies beyond it. The worth of that information is the whole dilemma.

Make it concrete. Add a bonus for actions you have barely tried and act greedily on the result:

$$a_t=\arg\max_a\Big[\underbrace{\hat Q_t(a)}_{\text{exploit}}\;+\;\underbrace{c\sqrt{\tfrac{\ln t}{N_t(a)}}}_{\text{explore}}\Big]$$

The second term is exactly where exploration is spent: it is large for actions with a small count $N_t(a)$ and shrinks as that count grows. It is a stand-in for a quantity RL would love and cannot get — the option value of one more sample.

You cannot both maximize now and learn best. A rule that always exploits stops gathering the evidence it would need to discover that it is wrong.

Cheat sheet

$$\begin{aligned} \tau &= (S_0,A_0,R_1,S_1,A_1,R_2,\dots)\\[2pt] G_t &= \sum_{k=0}^{\infty}\gamma^{k}R_{t+k+1}\\[2pt] J(\pi) &= \mathbb{E}_{\tau\sim\pi}\!\big[G_0\big]\\[2pt] \pi_{*}(s) &= \arg\max_{a} Q_{*}(s,a)\\[2pt] a_t &= \arg\max_{a}\Big[\hat Q_t(a)+c\sqrt{\tfrac{\ln t}{N_t(a)}}\Big] \end{aligned}$$

Everything downstream — multi-armed bandits, $\varepsilon$-greedy, UCB, then MDPs, TD learning, Q-learning, policy gradients, PPO — is a way of sampling, estimating, or improving one of these five lines.
